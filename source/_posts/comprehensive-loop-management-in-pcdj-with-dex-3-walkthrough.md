## Comprehensive Loop Management in PCDJ with DEX 3 Walkthrough

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/08/storingandrecallingloops-coverimage.jpg?resize=530%2C298&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/08/storingandrecallingloops-coverimage.jpg?fit=530%2C298&ssl=1 "storingandrecallingloops-coverimage")

The [DEX 3.4 **DJ mixing software**](https://tools.techidaily.com/pcdj/products/) update dropped last week, and one of the new features included with the skin update is the ability to **store and recall loops**.

A [loop](https://en.wikipedia.org/wiki/Loop%5F%28music%29) allows you to **repeat a section of the playing track seamlessly** and in sync with the beat (_using out beat-grid technology_), and creating loops with DEX 3 is easy. You have traditional “_loop in and loop out_” buttons and dedicated buttons for automatic 1, 2, 4, 8, 16 and 32 beat loops — as well as 1/2 and 1/4 loop buttons with the ability to half size or double the loop length.

New Loop Toggle Button

![](https://i1.wp.com/pcdj.com/wp-content/uploads/2015/08/storingloops.jpg?fit=300%2C300&ssl=1 "storingloops")

The loop functions are all designed to create loops seamlessly on-the-fly, but what if you want to store loops to be recalled later – _much like [hot cues](https://tools.techidaily.com/pcdj/products/)?_

DEX 3.4 and the subsequent skin update provides a new “_Loop and Cues_” toggle button located under each deck. Press the button to swap between cue and loop storage points. Then, while in a loop, press one of the 5 available loop storage buttons/points to save the loop. The loop will now be stored indefinitely and can be cleared by right-clicking the loop button (1-5).

You will also see “_white flags_” along the track timeline that represent the position of the stored loop, a great visual reference to know which loop you may want to trigger and when.
